# Polaris Executor

A modern Roblox executor built with a clean interface, smooth design, and a focus on creating a executor that can execute anything.

Polaris Executor is a UI-focused project designed to showcase what a polished scripting environment could look like. It features a custom editor layout, modern controls, and a simple workflow inspired by professional development tools.

## ✨ Features

- 🖥️ Modern dark-themed interface
- ✏️ Custom script editor layout
- ⚡ Smooth and responsive UI
- 🎨 Clean design with customizable elements
- 📁 Organized project structure
- 🔧 Built with C# and Windows Forms

## 🛠️ Built With

- C#
- .NET Framework 4.8
- Windows Forms
- Guna UI2
- Visual Studio

## 🚀 Installation

1. Download the latest release
2. Extract the files
3. Open Polaris Executor
4. Enjoy the interface

## 📌 About

Polaris Executor is a personal project created to execute scripts, while also doing application development, and creating a professional-looking desktop experience.

This project is for educational and design purposes.
